# data-centres-analysis
Учебный проект по анализу количества дата-центров в различных странах.

Источник: CSV-файл с сайты keggle - World Data Centers (https://www.kaggle.com/datasets/rockyt0/world-data-centers?resource=download&select=reported_totals.csv)

Период: февраль

Инструменты:
1) Google Colab
2) Python

Что было сделано:
1) найдено медианное значение количества дата-центров стран
2) посчитана разница между показателями стран и медианным значением
3) построены графики топ-15 стран и их отклонения от медианы

Выводы:
1) лидером является США с большим отрывом
2) медианное знчаение равно 202.0
3) отрицательная разница между медианным значением и количеством дата центров была у 10 стран

Файлы:
`data_centers_analysis.ipynb` - код
`reported_totals.csv` - исходные данные
`graphs/` - графики
